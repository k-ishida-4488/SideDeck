# SideDeck (v1.0.0)

> Googleカレンダー連携対応のスマートタスク管理ツールです。

## 📖 概要
**SideDeck** は、Google Chromeのサイドパネル上で動作するスマートなタスク管理拡張機能です。  
Web閲覧やメール確認をしながら、画面右側のサイドパネルで即座にタスクの追加・編集・カテゴリ分類・Googleカレンダー連携が行えます。

---

## 🚀 主な機能・特徴

### 1. 爆速タスク追加＆画像OCR解析
- **クリップボード＆ドロップ追加：** コピーしたテキストや画像を「Ctrl+V」やドラッグ＆ドロップで一瞬でタスク化。
- **画像OCR（Tesseract.js）：** 画像内の文字を自動解析して本文テキストへ変換。
- **自動ソース判定：** Mail(Gmail)、Teams、Google Chatなどの閲覧元を自動で判別してバッジ表示。

### 2. 高度なカテゴリ管理＆ドラッグ並べ替え
- **未分類固定：** 「📁 未分類」カテゴリが常に画面の最上部に固定表示されます。
- **カテゴリの自由な並べ替え：** 「未分類」以外のカテゴリ枠をドラッグ＆ドロップでお好みの順序に並べ替え可能。
- **複数カテゴリ対応：** 1つのタスクに「仕事」「買物」など複数のカテゴリを同時に割り当て可能。
- **完全同期完了：** 複数カテゴリに表示されているタスクも、1箇所で「完了」にすれば全表示から一括同期移動。
- **安全なカテゴリ削除：** ドロップダウン選択でカテゴリを削除しても、中のチケットは「未分類」へ自動保護。

### 3. 直感的なインライン編集＆Googleカレンダー連携
- **ダブルクリック編集：** 件名・本文・カテゴリタグをダブルクリックで直接書き換え＆複数チェックボックス選択。
- **Googleカレンダー連携：** 締切日を設定すると、ワンクリックでGoogleカレンダーの予定作成画面を呼び出し。
- **完了履歴のカテゴリ管理：** 完了したタスクもカテゴリごとに折りたたんで表示。完了後もカテゴリの再編集が可能。

### 4. 洗練された階層型スマートUI
- **2列ドロップダウンメニュー：** 上部ボタンを「➕ チケット追加」と「📁 カテゴリ管理」の2つに集約し、画面をスッキリ整理。
- **バックアップ＆復元：** データをJSONファイルとしてローカルへ保存・一括復元が可能。

## 📂 ファイル構成

- `manifest.json` : 拡張機能設定ファイル（Manifest V3 / 16,32,48,128pxマルチアイコン定義）
- `background.js` : サイドパネル起動用バックグラウンドスクリプト
- `sidepanel.html` : 階層型UIレイアウト画面
- `sidepanel.js` : タスク・カテゴリ・ストレージ制御プログラム（v1.0.0）
- `content.js` : コンテンツスクリプト（ダミー）
- `icon16.png`〜`icon128.png` : アプリケーションアイコン

---

## 🛠️ インストール方法

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、SideDeckのフォルダを選択します。
